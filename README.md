# eBay Data Scraper

Designed and developed an automated web scraper to collect, filter, and organize product listings from multiple eBay search pages using Python, Selenium, and BeautifulSoup.

## 🚀 Key Features & Implementation
* **Multi-Page Scraping**: Developed a robust scraper that automatically handles pagination to collect product listings from multiple pages.
* **Targeted Filtering**: Implemented custom filtering functionality to isolate data by specific keywords and custom price ranges.
* **Data Processing**: Processed, cleaned, and organized the raw scraped data into structured formats ready for downstream analysis.

## 📂 Project Structure
* `ebay_scraper.py`: Main script containing the Selenium automation and BeautifulSoup parsing logic.
* `requirements.txt`: Reference document listing required libraries for running the scraper.
